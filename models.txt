1. ITEMS
- id: Unique identifier for the item (e.g., 1)
- item_name: Name of the item (e.g., Rice 5kg)
- category: Item category or type (e.g., Groceries)
- base_unit: Smallest standard unit (e.g., kg)
- purchase_price_per_unit: Purchase price per base unit (e.g., 2.50)
- selling_price_per_unit: Selling price per base unit (e.g., 3.00)
- stock_quantity: Quantity in base units (e.g., 100)

2. ITEM UNITS
- id: Unique identifier for the unit (e.g., 1)
- item_id: Reference to Items (e.g., 1)
- unit_name: Name of the unit (e.g., sack)
- pack_quantity: Number of base units per unit (e.g., 20)
- purchase_price: Purchase price per unit (e.g., 50.00)
- selling_price: Selling price per unit (e.g., 60.00)
- note: Additional notes (e.g., Premium quality)

3. CUSTOM PRICING
- id: Unique identifier for the custom price (e.g., 1)
- item_id: Reference to Items (e.g., 1)
- title: Title of the custom pricing (e.g., Bulk Discount)
- quantity: Number of base units covered (e.g., 50)
- price: Total price for the quantity (e.g., 140.00)
- note: Additional notes (e.g., For restaurants)
- active: Whether pricing is active (e.g., true)
- start_date: Start date for the custom price (e.g., 2024-01-01)
- end_date: End date for the custom price (e.g., 2024-12-31)
